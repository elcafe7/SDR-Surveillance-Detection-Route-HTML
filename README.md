# SDR Quick: Surveillance Detection Route Generator

A mission-critical, high-contrast, and mobile-optimized web tool for planning and executing **Surveillance Detection Routes (SDR)** for both foot and vehicle operations.

## 🚀 Overview

The **SDR Quick** tool provides an interactive, glassmorphism-themed interface designed for low-light environments. It streamlines the process of planning surveillance detection by providing a structured checklist and reporting framework for operational security (OPSEC).

### Key Features
- **Operational Versatility:** Optimized for both **Foot** and **Driving** SDR missions.
- **High-Contrast Interface:** Dark-mode "Glassmorphism" UI designed for tactical use and reduced eye strain in low-light conditions.
- **Progress Tracking:** Interactive progress bar ensures full completion of the detection route planning.
- **Privacy-Centric:** Zero data exfiltration. All processing is handled locally in the browser's memory.
- **Mobile-First Design:** Responsive layout optimized for field use on smartphones and tablets.

## 🛠️ Installation & Usage

### Direct Usage
1. Clone the repository or download the `index.html` file.
2. Open `index.html` in any modern web browser.

### Local Development / Hosting
```bash
git clone https://github.com/elcafe7/SDR-Surveillance-Detection-Route-HTML.git
cd SDR-Surveillance-Detection-Route-HTML
# Serve locally using Python
python3 -m http.server 8080
```

## 📖 Core Workflow
1. **Initialize:** Select the mission type (Foot or Driving).
2. **Execute Checklist:** Follow the guided prompts for turns, stops, and "burn" points.
3. **Verify:** Review the generated route details.
4. **Export:** Copy the finalized route to the clipboard for secure transmission or local saving.
